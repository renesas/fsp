Detailed Description

Motor Tuner for PM motors on RA MCUs. This module implements the Motor tuner Interface.

Overview

The Motor Tuner module provides automatic motor parameter identification functionality for Permanent Magnet Synchronous Motors (PMSM). It identifies key motor parameters required for Field Oriented Control (FOC) without requiring prior knowledge of motor specifications.

Features

The Motor Tuner HAL module has the following key features:

  • Multiple identification methods:
    • Differential method for resistance identification
    • RLS (Recursive Least Squares) method for inductance identification
    • DFT (Discrete Fourier Transform) method for inductance verification
    • Open-loop method for back-EMF constant identification
  • Progress monitoring during identification process
  • Error detection and handling during tuning operations

Parameter Identification Stages

The motor tuner performs parameter identification in the following sequence:

Stage Description Parameters Identified
INIT Initialization and offset calibration -
VOLTERR Voltage error measurement (Optional) Voltage error LUT
R_DIFF Resistance identification using differential method R
RLD_RLS d-axis inductance identification using RLS method Ld (preliminary)
RLD_DFT d-axis inductance verification using DFT method Ld (refined)
LQ_RLS q-axis inductance identification using RLS method Lq (preliminary)
LQ_DFT q-axis inductance verification using DFT method Lq (refined)
KE Back-EMF constant identification using open-loop method Ke
JD Mechanical parameter identification J, D
END Identification complete -

Clock Configuration

The Motor Tuner module timing is based on the PWM carrier frequency and the configured control periods. Configure the PWM frequency and control periods according to your motor and inverter specifications.

Pin Configuration

This module does not directly use I/O pins. Pin configuration is handled by the underlying motor driver and ADC modules.

Usage Notes

State Machine

The motor tuner operates according to the following state machine:

  • READY: Tuner is initialized and ready to start identification
  • RUNNING: Parameter identification is in progress
  • COMPLETED: All parameters have been successfully identified
  • ERROR: An error occurred during identification
  • RESET: Tuner is being reset to initial state

Callback Function

The motor tuner requires periodic calls to both inner loop and outer loop processing functions:

  • innerLoopProcess: Should be called at the PWM carrier frequency (current control loop)
  • outerLoopProcess: Should be called at the speed control frequency

Setting Known Parameters

If some motor parameters are already known, they can be set before starting the identification process using knownParamSet. Setting a non-zero value for a parameter will skip the identification of that parameter.

Voltage Error Compensation

The voltage error identification stage generates a lookup table that compensates for inverter non-linearities such as dead-time effects. This lookup table can be retrieved using identifiedVoltageErrorGet and applied to the motor control system.

Error Handling

When an error occurs during identification:

  1. The tuner status changes to MOTOR_TUNER_STATUS_ERROR
  2. The error code can be retrieved using errorGet
  3. Call reset to return to the READY state
  4. Optionally, call start to retry the identification

Limitations

Developers should be aware of the following limitations when using the Motor Tuner:

  • The motor must be at standstill before starting the identification process for electrical parameter identification
  • The motor shaft must be free to rotate during mechanical parameter (J, D) and back-EMF constant (Ke) identification
  • The identification accuracy depends on the quality of current measurements and the stability of the DC bus voltage
  • High-frequency noise in current measurements may affect inductance identification accuracy
  • The motor should not be loaded during the identification process
  • Only the functions/types/macros exposed via rm_motor_tuner_pm.h and rm_motor_tuner_api.h should be accessed by user code and that the contents of the other headers is subject to change.

Examples

Motor Tuner Basic Example

This is a basic example of minimal use of the motor tuner in an application.

err = RM_MOTOR_TUNER_PM_Open(&g_motor_tuner_ctrl, &g_motor_tuner_cfg);
err = RM_MOTOR_TUNER_PM_KnownParamSet(&g_motor_tuner_ctrl, MOTOR_TUNER_PARAM_TYPE_POLE_PAIRS, known_pole_pairs);
handle_error(err);
/* Set rated current for identification. */
err =
RM_MOTOR_TUNER_PM_KnownParamSet(&g_motor_tuner_ctrl, MOTOR_TUNER_PARAM_TYPE_RATED_CURRENT, motor_rated_current);
handle_error(err);
err = RM_MOTOR_TUNER_PM_Start(&g_motor_tuner_ctrl);
handle_error(err);
err = RM_MOTOR_TUNER_PM_StatusGet(&g_motor_tuner_ctrl, &status);
handle_error(err);
uint16_t error_code;
err = RM_MOTOR_TUNER_PM_ErrorGet(&g_motor_tuner_ctrl, &error_code);
handle_error(err);
err = RM_MOTOR_TUNER_PM_Reset(&g_motor_tuner_ctrl);
handle_error(err);
err = RM_MOTOR_TUNER_PM_IsActive(&g_motor_tuner_ctrl, &is_active);
handle_error(err);

Motor Tuner Progress and Parameter Retrieval Example

This example demonstrates how to monitor progress and retrieve identified parameters.

err = RM_MOTOR_TUNER_PM_ProgressGet(&g_motor_tuner_ctrl, &progress);
handle_error(err);
float resistance;
float ld;
float lq;
float ke;
float inertia;
float friction;
err = RM_MOTOR_TUNER_PM_IdentifiedParamGet(&g_motor_tuner_ctrl, MOTOR_TUNER_PARAM_TYPE_PMSM_R, &resistance);
handle_error(err);
err = RM_MOTOR_TUNER_PM_IdentifiedParamGet(&g_motor_tuner_ctrl, MOTOR_TUNER_PARAM_TYPE_PMSM_LD, &ld);
handle_error(err);
err = RM_MOTOR_TUNER_PM_IdentifiedParamGet(&g_motor_tuner_ctrl, MOTOR_TUNER_PARAM_TYPE_PMSM_LQ, &lq);
handle_error(err);
err = RM_MOTOR_TUNER_PM_IdentifiedParamGet(&g_motor_tuner_ctrl, MOTOR_TUNER_PARAM_TYPE_PMSM_KE, &ke);
handle_error(err);
err = RM_MOTOR_TUNER_PM_IdentifiedParamGet(&g_motor_tuner_ctrl, MOTOR_TUNER_PARAM_TYPE_INERTIA, &inertia);
handle_error(err);
err = RM_MOTOR_TUNER_PM_IdentifiedParamGet(&g_motor_tuner_ctrl, MOTOR_TUNER_PARAM_TYPE_VISCOUS_FRICTION, &friction);
handle_error(err);

This function should be called from the PWM interrupt handler.

err = RM_MOTOR_TUNER_PM_InnerLoopProcess(&g_motor_tuner_ctrl, p_in, p_out);

Motor Tuner Outer Loop Example

RM_MOTOR_TUNER_PM_OuterLoopProcess(&g_motor_tuner_ctrl);

This example shows how to retrieve the voltage error lookup table after identification.

err = RM_MOTOR_TUNER_PM_IdentifiedVoltageErrorGet(&g_motor_tuner_ctrl, &voltage_error_lut, &rdc);

Motor Tuner Set Voltage Error Table Example

This example shows how to set a voltage error lookup table with known values.

err = RM_MOTOR_TUNER_PM_VoltageErrorSet(&g_motor_tuner_ctrl, &voltage_error_lut);
handle_error(err);

Motor Tuner Stop Example

This example shows how to stop the tuner operation.

err = RM_MOTOR_TUNER_PM_Stop(&g_motor_tuner_ctrl);
handle_error(err);

Motor Tuner Abort Example

This example shows how to abort the tuner operation with an error code.

err = RM_MOTOR_TUNER_PM_Abort(&g_motor_tuner_ctrl, 1);
