Motor tuner Interface
Interfaces » Motor

Detailed Description

Interface for motor tuner functions.

Summary

The Motor Tuner interface provides motor parameter estimation and tuning functionality.

◆ motor_tuner_status_t

enum motor_tuner_status_t

Indicates the status of Tuner. Main transitions:

  • READY -> RUNNING : START or RESUME command
  • RUNNING -> READY : STOP command
  • RUNNING -> ERROR : An error occurs
  • RUNNING -> COMPLETED : Identification (ID) completed
  • ERROR -> RESET : RESET command
  • ERROR -> RUNNING : RESUME command
  • RESET -> READY : Always (returns to READY)
  • COMPLETED -> RUNNING : START or RESUME command
Enumerator
MOTOR_TUNER_STATUS_READY 

Ready to run (idle)

MOTOR_TUNER_STATUS_RUNNING 

Running (identification/processing in progress)

MOTOR_TUNER_STATUS_ERROR 

Error occurred.

MOTOR_TUNER_STATUS_RESET 

Reset state.

MOTOR_TUNER_STATUS_COMPLETED 

Operation completed.
