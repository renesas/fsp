Detailed Description

Motor control on RA MCUs. This module implements the Motor Interface.

Overview

The Motor Control module provides a high-level interface for controlling motor rotation. It manages the motor state machine, handles speed control, and provides error detection and recovery mechanisms.

Features

The Motor Control HAL module has the following key features:

  • State machine management for motor control (STOP, RUN, ERROR states)
  • Speed reference setting and actual speed monitoring
  • Error detection and handling with automatic state transitions
  • Integration with motor algorithm layer (PM FOC)
  • Optional trajectory control support
  • Callback mechanism for event notification

Pin Configuration

This module does not directly use I/O pins. Pin configuration is handled by the underlying motor algorithm and driver modules.

Usage Notes

State Machine

The motor control module uses a state machine with three states:

  • STOP: Motor is stopped and not rotating
  • RUN: Motor is active and rotating
  • ERROR: An error has been detected

State transitions are triggered by the following events:

  • EVENT_STOP: Transitions to STOP state (from RUN)
  • EVENT_RUN: Transitions to RUN state (from STOP)
  • EVENT_ERROR: Transitions to ERROR state (from any state)
  • EVENT_RESET: Transitions to STOP state (from ERROR)

Error Handling

When an error is detected, the motor control module:

  1. Stores the error information
  2. Transitions to ERROR state
  3. Resets the motor algorithm layer
  4. Invokes the user callback (if registered)

To recover from an error:

  1. Clear the error condition
  2. Call RM_MOTOR_CONTROL_Reset to return to STOP state
  3. Call RM_MOTOR_CONTROL_Run to restart motor rotation

Callback Events

The following callback events are supported:

  • MOTOR_CALLBACK_EVENT_SPEED_BACKWARD: Speed control cycle completed
  • MOTOR_CALLBACK_EVENT_CURRENT_BACKWARD: Current control cycle completed
  • MOTOR_CALLBACK_EVENT_ERROR: Error detected

Limitations

Developers should be aware of the following limitations when using the Motor Control module:

  • The module must be opened before any other API functions are called.
  • Speed reference should be set after calling RM_MOTOR_CONTROL_Run.
  • RM_MOTOR_CONTROL_Reset is only valid when the motor is in ERROR state.
  • Position control functions (RM_MOTOR_CONTROL_PositionSet, RM_MOTOR_CONTROL_WaitStopFlagGet, RM_MOTOR_CONTROL_FunctionSelect) return FSP_ERR_UNSUPPORTED.

Examples

Basic Example

This is a basic example of minimal use of the motor control in an application.

/* Initializes the module. */
err = RM_MOTOR_CONTROL_Open(&g_motor_control_ctrl, &g_motor_control_cfg);
/* Start motor rotation. */
err = RM_MOTOR_CONTROL_Run(&g_motor_control_ctrl);
/* Set speed reference. */
err = RM_MOTOR_CONTROL_SpeedSet(&g_motor_control_ctrl, 1000.0F);
/* Get current speed. */
float speed_rpm = 0.0F;
err = RM_MOTOR_CONTROL_SpeedGet(&g_motor_control_ctrl, &speed_rpm);
/* Get motor status. */
uint8_t status = 0;
err = RM_MOTOR_CONTROL_StatusGet(&g_motor_control_ctrl, &status);
/* Check for errors. */
uint16_t error = 0;
err = RM_MOTOR_CONTROL_ErrorCheck(&g_motor_control_ctrl, &error);
/* Set error information. */
err = RM_MOTOR_CONTROL_ErrorSet(&g_motor_control_ctrl, MOTOR_ERROR_NONE);
/* Stop motor rotation. */
err = RM_MOTOR_CONTROL_Stop(&g_motor_control_ctrl);
/* Reset motor control. */
err = RM_MOTOR_CONTROL_Reset(&g_motor_control_ctrl);
/* Close the module. */
err = RM_MOTOR_CONTROL_Close(&g_motor_control_ctrl);

Complete Example

This example demonstrates a complete motor control sequence including initialization, running, and error handling.

#include "rm_motor_control.h"
/* Motor control instance */
extern motor_instance_t g_motor0;
/* Error handler callback */
void motor_callback (motor_callback_args_t * p_args)
{
switch (p_args->event)
{
case MOTOR_CALLBACK_EVENT_SPEED_BACKWARD:
/* Speed control processing completed */
break;
case MOTOR_CALLBACK_EVENT_CURRENT_BACKWARD:
/* Current control processing completed */
break;
case MOTOR_CALLBACK_EVENT_ERROR:
/* Error detected - handle appropriately */
break;
default:
break;
}
}
void motor_control_example (void)
{
fsp_err_t err;
uint8_t status;
float speed_rpm;
uint16_t error;
/* Open the motor control module */
err = RM_MOTOR_CONTROL_Open(g_motor0.p_ctrl, g_motor0.p_cfg);
if (FSP_SUCCESS != err)
{
/* Handle error */
return;
}
/* Start motor rotation */
err = RM_MOTOR_CONTROL_Run(g_motor0.p_ctrl);
if (FSP_SUCCESS != err)
{
/* Handle error */
return;
}
/* Set target speed to 1000 RPM */
err = RM_MOTOR_CONTROL_SpeedSet(g_motor0.p_ctrl, 1000.0F);
/* Main loop */
while (true)
{
/* Check for errors */
err = RM_MOTOR_CONTROL_ErrorCheck(g_motor0.p_ctrl, &error);
if (MOTOR_ERROR_NONE != error)
{
/* Error detected - stop and reset */
RM_MOTOR_CONTROL_Stop(g_motor0.p_ctrl);
RM_MOTOR_CONTROL_Reset(g_motor0.p_ctrl);
break;
}
/* Get current status */
RM_MOTOR_CONTROL_StatusGet(g_motor0.p_ctrl, &status);
/* Get current speed */
RM_MOTOR_CONTROL_SpeedGet(g_motor0.p_ctrl, &speed_rpm);
/* Application processing */
}
/* Close the module */
RM_MOTOR_CONTROL_Close(g_motor0.p_ctrl);
}

fsp_err_t RM_MOTOR_CONTROL_Open ( motor_ctrl_t *const  p_ctrl,
motor_cfg_t const *const  p_cfg 
)

Configure the MOTOR in register start mode. Implements motor_api_t::open.

This function should only be called once as MOTOR configuration registers can only be written to once so subsequent calls will have no effect.

Example:

/* Initializes the module. */
err = RM_MOTOR_CONTROL_Open(&g_motor_control_ctrl, &g_motor_control_cfg);
Return values
FSP_SUCCESSMOTOR successfully configured.
FSP_ERR_ASSERTIONNull pointer, or one or more configuration options is invalid.
FSP_ERR_ALREADY_OPENModule is already open. This module can only be opened once.
FSP_ERR_INVALID_ARGUMENTConfiguration parameter error.
