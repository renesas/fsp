Motor sensor Interface
Interfaces » Motor

Detailed Description

Interface for motor angle and speed estimation functions.

Summary

The Motor Sensor interface provides rotor angle and rotational speed estimation from various sensor types (BEMF observer, Hall sensors, etc.).
