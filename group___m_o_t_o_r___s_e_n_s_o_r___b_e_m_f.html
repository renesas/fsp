Detailed Description

Motor Sensor BEMF on RA MCUs. This module implements the Motor sensor Interface.

Overview

The Motor Sensor BEMF module provides sensorless rotor angle and speed estimation using a Back-EMF (BEMF) observer combined with a Phase-Locked Loop (PLL). This module is designed for brushless DC (BLDC) and permanent magnet synchronous motor (PMSM) control applications where encoder or Hall sensor feedback is not available.

Features

The Motor Sensor BEMF module has the following key features:

  • Sensorless rotor angle estimation using BEMF observer
  • Speed estimation using PLL (Phase-Locked Loop)
  • Open-loop startup with configurable d-axis current injection
  • Smooth transition from open-loop to sensorless control
  • Optional open-loop damping for improved stability
  • Configurable observer and PLL bandwidth parameters

Pin Configuration

This module does not use I/O pins directly. Current and voltage measurements are provided by the inner loop (FOC) module.

Usage Notes

Startup Sequence

The BEMF observer requires sufficient back-EMF voltage for accurate angle estimation. During startup:

  1. The module injects d-axis current (Id) to establish rotor flux
  2. Speed reference is ramped up in open-loop mode
  3. When speed exceeds the threshold (f4_id_down_speed_mech_rad), the module transitions to sensorless mode
  4. The PLL locks onto the estimated angle and provides continuous tracking

Parameter Tuning

  • Observer bandwidth (e_obs_omega): Higher values provide faster response but may amplify noise
  • PLL bandwidth (pll_est_omega): Should be lower than observer bandwidth for stability
  • Damping ratios (e_obs_zeta, pll_est_zeta): Values around 1.0 provide critically damped response

Open-Loop Damping

When openloop_damping is enabled, the module applies active damping during open-loop operation to suppress oscillations. This is particularly useful for motors with low inertia.

Limitations

Developers should be aware of the following limitations:

  • The BEMF observer requires minimum motor speed for accurate estimation (typically > 5% of rated speed)
  • Estimation accuracy depends on accurate motor parameter values (resistance, inductance, flux linkage)
  • High-frequency noise in current measurements can affect estimation quality
  • The module assumes sinusoidal back-EMF waveform
  • Only the functions/types/macros exposed via rm_motor_sensor_bemf.h and rm_motor_sensor_api.h should be accessed by user code and that the contents of the other headers is subject to change.

Examples

Basic Example

This is a basic example of minimal use of the Motor Sensor BEMF module in an application.

/* Configure BEMF observer extended parameters */
static const motor_sensor_bemf_extended_cfg_t g_motor_sensor_bemf_ext_cfg =
{
.e_obs_omega = 300.0F, /* Natural frequency of BEMF observer [Hz] */
.e_obs_zeta = 1.0F, /* Damping ratio of BEMF observer */
.pll_est_omega = 20.0F, /* Natural frequency of PLL speed estimate loop [Hz] */
.pll_est_zeta = 1.0F, /* Damping ratio of PLL speed estimate loop */
.openloop_damping = MOTOR_MCSENSOR_OPENLOOP_DAMPING_DISABLE,
.less_switch = MOTOR_MCSENSOR_LESS_SWITCH_DISABLE,
.ol_param =
{
.f4_ol_id_ref = 1.0F, /* Open-loop d-axis current reference [A] */
.f4_ol_id_up_step = 0.001F, /* Id ramp-up step [A/control period] */
.f4_ol_id_down_step = 0.001F, /* Id ramp-down step [A/control period] */
.f4_ol_iq_down_step_ratio = 0.1F, /* Iq ramp-down step ratio */
.f4_id_up_speed_mech_rad = 10.0F, /* Speed threshold for Id ramp-up [rad/s mech] */
.f4_id_down_speed_mech_rad = 50.0F, /* Speed threshold for Id ramp-down [rad/s mech] */
.f4_opl2less_sw_time = 0.5F, /* Open-loop to sensorless switching time [s] */
.f4_switch_phase_err_rad = 5.0F, /* Phase error threshold for switching [deg] */
},
.ol_sub_param =
{
.f_fb_speed_limit_rate = 1.0F,
},
.d_param =
{
.ed_hpf_omega = 10.0F, /* HPF natural frequency for open-loop damping [Hz] */
.ol_damping_zeta = 1.0F, /* Damping ratio for open-loop damping */
},
};
/* Configure BEMF sensor module */
static const motor_sensor_cfg_t g_motor_sensor_bemf_cfg =
{
.p_context = NULL,
.p_extend = &g_motor_sensor_bemf_ext_cfg,
};
/* Control structure */
static motor_sensor_bemf_instance_ctrl_t g_motor_sensor_bemf_ctrl;
void rm_motor_sensor_bemf_basic_example (void)
{
fsp_err_t err = FSP_SUCCESS;
/* Open and configure the BEMF sensor module */
err = RM_MOTOR_SENSOR_BEMF_Open(&g_motor_sensor_bemf_ctrl, &g_motor_sensor_bemf_cfg);
/* Handle any errors. This function should be defined by the user. */
handle_error(err);
/* Reset the BEMF sensor module variables */
err = RM_MOTOR_SENSOR_BEMF_Reset(&g_motor_sensor_bemf_ctrl);
handle_error(err);
/* Close the BEMF sensor module */
err = RM_MOTOR_SENSOR_BEMF_Close(&g_motor_sensor_bemf_ctrl);
handle_error(err);
}

Advanced Example

This example demonstrates the complete usage including angle/speed calculation in a control loop.

/* Pointers for angle and speed output */
static float * gp_speed_el;
static float * gp_angle_el;
static motor_sensor_output_t * gp_sensor_output;
/* Example inner loop shared data (normally provided by FOC module) */
static motor_shared_inner_to_position_speed_t g_from_inner;
static motor_shared_inner_to_outer_foc_t g_inner_data;
static motor_shared_outer_to_position_speed_t g_outer_data;
void rm_motor_sensor_bemf_advanced_example (void)
{
fsp_err_t err = FSP_SUCCESS;
/* Open the BEMF sensor module */
err = RM_MOTOR_SENSOR_BEMF_Open(&g_motor_sensor_bemf_ctrl, &g_motor_sensor_bemf_cfg);
handle_error(err);
/* Set pointers for angle and speed, and configure shared data */
err = RM_MOTOR_SENSOR_BEMF_AngleSpeedInit(&g_motor_sensor_bemf_ctrl,
&gp_speed_el,
&gp_angle_el,
&gp_sensor_output,
(motor_sensor_input_inner_t *) &g_from_inner);
handle_error(err);
/* Update parameters (e.g., after motor parameter identification) */
err = RM_MOTOR_SENSOR_BEMF_ParameterUpdate(&g_motor_sensor_bemf_ctrl, &g_motor_sensor_bemf_cfg);
handle_error(err);
/* Main control loop example */
while (true)
{
/* (Inner loop would update g_inner_data with measured currents and voltages) */
/* Calculate angle and speed estimation */
err = RM_MOTOR_SENSOR_BEMF_AngleSpeedCalc(&g_motor_sensor_bemf_ctrl,
(motor_sensor_input_inner_t *) &g_inner_data,
(motor_sensor_input_outer_t *) &g_outer_data);
handle_error(err);
/* Access estimated angle and speed via pointers */
float current_angle_el = *gp_angle_el;
float current_speed_el = *gp_speed_el;
/* Get mechanical position and speed */
float pos_mech = 0.0F;
float speed_mech = 0.0F;
err = RM_MOTOR_SENSOR_BEMF_PositionSpeedGet(&g_motor_sensor_bemf_ctrl, &pos_mech, &speed_mech);
handle_error(err);
/* Use estimated values for motor control */
FSP_PARAMETER_NOT_USED(current_angle_el);
FSP_PARAMETER_NOT_USED(current_speed_el);
FSP_PARAMETER_NOT_USED(pos_mech);
FSP_PARAMETER_NOT_USED(speed_mech);
}
}
