Detailed Description

Motor hal driver on RA MCUs. This module implements the Motor Hal Driver Interface.

Overview

The Motor HAL Driver module provides hardware abstraction layer functions for motor control applications. It handles PWM modulation, ADC current sensing, and voltage control for three-phase motor drivers. This module serves as an interface between the motor control algorithm and the hardware peripherals (ADC, GPT).

Motor HAL Driver Block Diagram

Features

The Motor HAL Driver module has the following key features:

  • Supports multiple current sensing configurations:
    • 1-shunt current sensing
    • 2-shunt current sensing
    • 3-shunt current sensing
  • Multiple PWM modulation methods:
    • SPWM (Sinusoidal Pulse Width Modulation)
    • SVPWM (Space Vector Pulse Width Modulation)
    • DPWM (Discontinuous Pulse Width Modulation)
  • Automatic current offset calibration
  • Bootstrap circuit charging support
  • Phase voltage and current measurement
  • Support for multiple motor control (shared ADC instance)

Clock Configuration

The Motor HAL Driver uses GPT (General PWM Timer) for PWM generation. The PWM carrier frequency is determined by the GPT timer frequency and the carrier base count setting.

Pin Configuration

This module uses the following pins:

Pin Type Description
GPT PWM Output (UP, UN) U-phase high-side and low-side PWM output
GPT PWM Output (VP, VN) V-phase high-side and low-side PWM output
GPT PWM Output (WP, WN) W-phase high-side and low-side PWM output
ADC Input Phase current sensing (Iu, Iv, Iw)
ADC Input DC bus voltage sensing (Vdc)
ADC Input Phase voltage sensing (Vu, Vv, Vw) - optional

Usage Notes

Current Offset Calibration

Before motor operation begins, the module automatically performs current offset calibration. The calibration process measures the ADC offset values when no current is flowing through the motor.

The calibration count can be configured via offset_calc_count parameter. PWM output is disabled during calibration and automatically enabled after calibration completes. Use RM_MOTOR_HAL_DRIVER_FlagCurrentOffsetGet to check if calibration is complete. Use RM_MOTOR_HAL_DRIVER_CurrentOffsetRestart to restart calibration if needed.

Bootstrap Circuit Charging

For motor drivers with bootstrap circuits, the module provides bootstrap charging functionality:

Call RM_MOTOR_HAL_DRIVER_ChargeBootstrap periodically until charging is complete. Use RM_MOTOR_HAL_DRIVER_FlagBootstrapGet to check if bootstrap charging is complete. The charging time can be configured via charge_bootstrap_time parameter.

Shared ADC Instance Support

When using shared ADC instance for multiple motor control, follow these steps:

  1. Add (New) shared ADC instance in FSP Configurator.
  2. Configure the ADC module settings for your application.
  3. Set "Common | Shared ADC support" to "Enabled".
  4. Configure p_shared_cfg in the extended configuration.

Modulation Methods

The module supports three PWM modulation methods:

Method Description Voltage Utilization SPWM Sinusoidal PWM - Simple implementation ~86.6% SVPWM Space Vector PWM - Better DC bus utilization ~100% DPWM Discontinuous PWM - Reduced switching losses ~100%

Callback Function

The module calls the user-provided callback function at each PWM carrier cycle (ADC conversion complete). This callback is typically used for current control processing.

Example callback usage:

void motor_current_callback(motor_hal_driver_callback_args_t * p_args)
{
if (MOTOR_HAL_DRIVER_EVENT_CURRENT == p_args->event)
{
/* Perform current control processing */
}
}

Motor HAL Driver Basic Example This is a basic example of minimal use of the Motor HAL Driver in an application.

void rm_motor_hal_driver_basic_example (void)
{
fsp_err_t err = FSP_SUCCESS;
/* Initializes the module. */
err = RM_MOTOR_HAL_DRIVER_Open(&g_motor_hal_driver_ctrl, &g_motor_hal_driver_cfg);
/* Handle any errors. This function should be defined by the user. */
handle_error(err);
/* Basically run this module at cyclic interrupt (e.g. included GPT PWM Carrier intterupt).
* This implementation is an example. */
/* Set the active into hal_driver. */
err = RM_MOTOR_HAL_DRIVER_Activate(&g_motor_hal_driver_ctrl);
handle_error(err);
/* Set phase voltage. */
err = RM_MOTOR_HAL_DRIVER_PhaseVoltageSet(&g_motor_hal_driver_ctrl, 1.0F, 1.0F, 1.0F);
handle_error(err);
/* Get current data. */
motor_hal_driver_current_dataset_t current_data = {0.0F, 0.0F, 0.0F, 0.0F, 1.0F};
err = RM_MOTOR_HAL_DRIVER_CurrentGet(&g_motor_hal_driver_ctrl, &current_data);
handle_error(err);
/* Get voltage data. */
motor_hal_driver_voltage_dataset_t voltage_data = {0.0F, 0.0F, 0.0F};
err = RM_MOTOR_HAL_DRIVER_OutputVoltageGet(&g_motor_hal_driver_ctrl, &voltage_data);
handle_error(err);
/* Get the flag of A/D convderted current offset */
uint8_t offset_flag = 0U;
err = RM_MOTOR_HAL_DRIVER_FlagCurrentOffsetGet(&g_motor_hal_driver_ctrl, &offset_flag);
handle_error(err);
/* Get the flag of Bootstrap. */
uint8_t bootstrap_flag = 0U;
err = RM_MOTOR_HAL_DRIVER_FlagBootstrapGet(&g_motor_hal_driver_ctrl, &bootstrap_flag);
handle_error(err);
/* Charge the Bootstrap circuit. */
err = RM_MOTOR_HAL_DRIVER_ChargeBootstrap(&g_motor_hal_driver_ctrl);
handle_error(err);
/* Update the parameters. */
err = RM_MOTOR_HAL_DRIVER_ParameterUpdate(&g_motor_hal_driver_ctrl, &g_motor_hal_driver_cfg);
handle_error(err);
/* Clear the active into hal_driver. */
err = RM_MOTOR_HAL_DRIVER_Deactivate(&g_motor_hal_driver_ctrl);
handle_error(err);
/* Recalculate the A/D convderted current offset. */
offset_flag = 0U;
err = RM_MOTOR_HAL_DRIVER_CurrentOffsetRestart(&g_motor_hal_driver_ctrl);
handle_error(err);
/* Reset the module. */
err = RM_MOTOR_HAL_DRIVER_Reset(&g_motor_hal_driver_ctrl);
handle_error(err);
/* Close the module. */
err = RM_MOTOR_HAL_DRIVER_Close(&g_motor_hal_driver_ctrl);
handle_error(err);
}

Motor HAL Driver Advanced Example

This example demonstrates a more complete motor control sequence including bootstrap charging and current control.

void rm_motor_hal_driver_advanced_example (void)
{
fsp_err_t err = FSP_SUCCESS;
uint8_t offset_flag = 0U;
uint8_t bootstrap_flag = 0U;
/* Open the module */
err = RM_MOTOR_HAL_DRIVER_Open(&g_motor_hal_driver_ctrl, &g_motor_hal_driver_cfg);
assert(FSP_SUCCESS == err);
/* Charge bootstrap circuit (if applicable) */
do
{
err = RM_MOTOR_HAL_DRIVER_ChargeBootstrap(&g_motor_hal_driver_ctrl);
assert(FSP_SUCCESS == err);
err = RM_MOTOR_HAL_DRIVER_FlagBootstrapGet(&g_motor_hal_driver_ctrl, &bootstrap_flag);
assert(FSP_SUCCESS == err);
} while (0U == bootstrap_flag);
/* Wait for current offset calibration to complete */
do
{
err = RM_MOTOR_HAL_DRIVER_FlagCurrentOffsetGet(&g_motor_hal_driver_ctrl, &offset_flag);
assert(FSP_SUCCESS == err);
} while (0U == offset_flag);
/* Motor control loop */
while (true)
{
motor_hal_driver_current_dataset_t current_data;
/* Get current data */
err = RM_MOTOR_HAL_DRIVER_CurrentGet(&g_motor_hal_driver_ctrl, &current_data);
assert(FSP_SUCCESS == err);
/* Calculate phase voltages based on current feedback */
/* (User implements current control algorithm here) */
ccal_num_t v_u = 0.0F;
ccal_num_t v_v = 0.0F;
ccal_num_t v_w = 0.0F;
/* Set phase voltage */
err = RM_MOTOR_HAL_DRIVER_PhaseVoltageSet(&g_motor_hal_driver_ctrl, v_u, v_v, v_w);
assert(FSP_SUCCESS == err);
}
}
