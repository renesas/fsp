lwIP SNMP Agent
Modules » Networking

This module provides the lwIP SNMP Agent integration documentation.

Overview

The LwIP SNMP Agent provides a lightweight implementation of the Simple Network Management Protocol (SNMP) for embedded systems. The documentation for the library can be found at the following link: lwIPSNMP.

Features

The LwIP SNMP Agent supports the following protocol versions:

  • SNMPv1
  • SNMPv2c
  • SNMPv3 (experimental; not fully validated in the current release)

Usage Notes

  • Memory Configuration: Large MIBs or processing multiple SNMP requests simultaneously may require increasing the stack size and memory pool configurations in lwipopts.h, as well as the thread stack size if using an RTOS.
  • Ports: By default, the SNMP agent listens for incoming requests on UDP port 161, while TRAP/INFORM messages are sent to the manager on UDP port 162.
  • SNMPv3: When SNMPv3 is used, several functions from snmpv3.h must be implemented by the user. This is mainly for user management and persistence handling.

How to Create and Compile Custom MIBs for lwIP SNMP Agent

The lwIP SNMP Agent supports extending the standard MIB-2 tree with your own Custom MIBs (Management Information Base). This guide explains how to write a custom MIB file and generate the corresponding C code using the LwipMibCompiler tool.

1. Create Your Custom MIB File

Before generating the C code, you need a valid MIB file that defines your custom objects (OIDs, scalars, tables, etc.) that the SNMP Agent will expose.

  • How to Create: You can write this file from scratch using any standard text editor (like VS Code, Notepad++) or use specialized MIB authoring tools. Ensure your syntax strictly follows the SMIv2 standard.
  • References & Templates: If you are new to writing MIBs, it is highly recommended to study the standard MIB files provided by the lwIP project. You can find excellent reference files (such as SNMPv2-MIB, IF-MIB, LLDP-MIB, etc.) in the Mibs directory of the compiler tool: LwipMibCompiler/Mibs

2. Set up the LwipMibCompiler Tool

The lwIP project provides a C# based tool called LwipMibCompiler to automatically generate C code (.c and .h files) from your MIB files.

  • Download the Tool: You can find the source code for the compiler in the official lwIP repository: LwipMibCompiler
  • Build the Tool:
    • Open the solution file (LwipMibCompiler.sln).
    • Build the project.
    • The executable LwipMibCompiler.exe will be generated in the LwipMibCompiler/bin/Debug/ folder.

3. Generate C Code from the MIB File

Once you have LwipMibCompiler.exe and your custom MIB file ready, you can generate the C code via the command line.

For advanced usage with command line, you can refer to the example scripts provided in the repository compile_udp_mib.cmd or compile_udp_mib.sh.

4. Integrate the Generated Code into Your Project

After generating the code, you need to link it to the lwIP SNMP Agent in your application.

  • Add Files to Project: Add the generated *.c* and *.h* files to your IDE/build system.
  • Implement the Callbacks: The generated *.c* file will contain "skeleton" functions (e.g., customSensor_get_value, customSensor_set_value). You must implement the actual logic inside these functions to read from or write to your hardware/variables.
  • Register the MIB: Finally, include the generated header and add your custom MIB to the lwIP SNMP Agent initialization sequence:
    #include "lwip/apps/snmp.h"
    #include "snmpv2-renesas.h" // Your generated header
    /* Array of MIBs to load into the agent */
    static const struct snmp_mib * my_snmp_mibs[] =
    {
    &mib2, /* Standard MIB-2 */
    &renesas /* Your Custom MIB (Name matches the MODULE-IDENTITY) */
    };
    void my_snmp_init(void)
    {
    /* Load the MIBs array */
    snmp_set_mibs(my_snmp_mibs, LWIP_ARRAYSIZE(my_snmp_mibs));
    /* Initialize SNMP Agent */
    snmp_init();
    }

Examples

Basic Example

This is a basic example of minimal use of the lwIP SNMP Agent APIs in an application.

Note
This example provides a basic implementation of an LwIP SNMPv2c agent based on the default MIB-II. For further details regarding custom MIB development and the LwIP SNMPv3 agent, refer to: LwipSNMP_Example
#include "lwip/init.h"
#include "lwip/apps/snmp.h"
#include "lwip/apps/snmp_mib2.h"
#define LWIP_SNMP_AGENT_EXAMPLE_MIB2_SYSDESC "LwIP SNMP Agent Test Device"
#define LWIP_SNMP_AGENT_EXAMPLE_MIB2_SYSNAME "RA-BOARD_TEST"
#define LWIP_SNMP_AGENT_EXAMPLE_MIB2_SYSCONTACT "Renesas_Test_Contact"
#define LWIP_SNMP_AGENT_EXAMPLE_MIB2_SYSLOCATION "Renesas-LAB-TEST"
#if SNMP_LWIP_MIB2
/* Define variables for SNMP sysLocation to make it accessible read/write */
static u8_t sys_location[] = LWIP_SNMP_AGENT_EXAMPLE_MIB2_SYSLOCATION;
static u16_t sys_location_len = sizeof(LWIP_SNMP_AGENT_EXAMPLE_MIB2_SYSLOCATION) - 1;
#endif
static const struct snmp_mib * mibs[] =
{
&mib2
};
void lwip_snmp_example();
static void lwip_snmp_agent_start(void);
/* LwIP SNMP example */
void lwip_snmp_example () {
struct netif netif;
ip_addr_t ipaddr;
ip_addr_t netmask;
ip_addr_t gw;
/* Initializing lwIP core. */
#if SNMP_USE_NETCONN
tcpip_init(NULL, NULL);
#else
lwip_init();
#endif
/* Set ip address of the board. */
IP4_ADDR(&ipaddr, 192, 168, 10, 4);
IP4_ADDR(&netmask, 255, 255, 255, 0);
IP4_ADDR(&gw, 192, 168, 10, 1);
#if SNMP_USE_NETCONN
netif_add(&netif, &ipaddr, &netmask, &gw, &g_lwip_ether0_instance, rm_lwip_ether_init, tcpip_input);
#else
netif_add(&netif, &ipaddr, &netmask, &gw, &g_lwip_ether0_instance, rm_lwip_ether_init, netif_input);
#endif
/* Set netif as default and enable. */
netif_set_default(&netif);
netif_set_up(&netif);
netif_set_link_up(&netif);
/* Start SNMP agent */
lwip_snmp_agent_start();
}
static void lwip_snmp_agent_start (void)
{
#if SNMP_LWIP_MIB2
#if SNMP_USE_NETCONN
snmp_threadsync_init(&snmp_mib2_lwip_locks, snmp_mib2_lwip_synchronizer);
#endif /* SNMP_USE_NETCONN */
/* Configure MIB2 parameters */
snmp_mib2_set_sysdescr((const u8_t *) LWIP_SNMP_AGENT_EXAMPLE_MIB2_SYSDESC, NULL);
snmp_mib2_set_sysname((u8_t *) LWIP_SNMP_AGENT_EXAMPLE_MIB2_SYSNAME, NULL, 0);
snmp_mib2_set_syscontact((u8_t *) LWIP_SNMP_AGENT_EXAMPLE_MIB2_SYSCONTACT, NULL, 0);
snmp_mib2_set_syslocation(sys_location, &sys_location_len, sizeof(sys_location));
#endif /* SNMP_LWIP_MIB2 */
/* Load the MIBs array into the SNMP Agent */
snmp_set_mibs(mibs, LWIP_ARRAYSIZE(mibs));
/* Initialize SNMP (call only once) */
snmp_init();
}
